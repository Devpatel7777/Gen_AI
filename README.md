# 🤖 Gen_AI Projects Collection

Welcome to **Gen_AI**, a collection of Generative AI applications built using **Python, LangChain, LangGraph, Google Gemini, Groq, and Streamlit**.

This repository demonstrates practical implementations of Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Prompt Engineering, AI Agents, and modern AI application development.

# 🚀 Projects Included

## 📘 1. AI Learning Coach – RAG Chatbot

An AI-powered document assistant that allows users to upload one or more PDF documents and interact with them using natural language.

### Features

- Multiple PDF Upload
- PDF Reading
- Intelligent Text Chunking
- Google Gemini Embeddings
- InMemory Vector Store
- Semantic Search
- LangGraph AI Agent
- Groq GPT-OSS-20B
- AI Chat Interface
- Conversation Memory

### Technology Stack

- Python
- Streamlit
- LangChain
- LangGraph
- Google Gemini Embeddings
- InMemoryVectorStore
